Privacy

Ultimo aggiornamento: 26 settembre 2026

In breve: MyDevAgent gira sul tuo PC. Non ha account e non manda telemetria. Noi non abbiamo server e non riceviamo i tuoi file, il tuo codice o le tue chat.

Il programma MyDevAgent

I modelli AI girano in locale con Ollama. Il tuo codice, le conversazioni, la memoria (#nota) e le statistiche (/stats) restano in file sul tuo computer. Puoi cancellarli quando vuoi.

MyDevAgent si collega a internet solo in questi casi:

  • Controllo della connessione: una richiesta vuota a gstatic.com/generate_204 (Google) per capire se sei online.
  • Aggiornamenti: /update e l'avviso all'avvio chiedono a GitHub se ci sono novità.
  • Ricerca web e lettura di pagine, quando le usi: la ricerca passa da DuckDuckGo, oppure da SearXNG, Tavily o Firecrawl se li hai configurati tu. Le pagine vengono scaricate dai siti che visiti.
  • Modelli, plugin e server MCP che scegli di scaricare o collegare: Ollama, GitHub o gli indirizzi che indichi tu.

Questi servizi hanno le loro informative sulla privacy e vedono il tuo indirizzo IP. Se non usi la ricerca web e non aggiorni, MyDevAgent funziona completamente offline.

Multigiocatore

Con /multi la tua sessione è visibile nella tua rete locale a chi ha il codice della stanza. Chi entra vede la conversazione e le modifiche ai file. Condividi il codice solo con persone di cui ti fidi.

MyDevAgent Studio

Lo Studio è basato su VSCodium, che non ha la telemetria di Microsoft. Il setup scarica Python, Ollama e MyDevAgent dai loro siti ufficiali.

Questo sito

  • Non usa cookie, statistiche di visita o pubblicità.
  • È ospitato su GitHub Pages. GitHub può registrare il tuo indirizzo IP per sicurezza: vedi la privacy di GitHub.
  • I caratteri arrivano da Google Fonts, che vede il tuo indirizzo IP.
  • I pulsanti per scaricare portano a GitHub.
