MyDevAgent è gratis e open source. Usandolo accetti questi termini. Sono pochi, e la parte importante è una sola: controlla sempre quello che fa l'AI.

MyDevAgent e MyDevAgent Studio sono rilasciati con licenza MIT. Puoi usarli, copiarli, modificarli e ridistribuirli, anche per lavoro, purché tu mantenga l'avviso di copyright e il testo della licenza. Il testo completo è nel file LICENSE.

Lo Studio è basato su VSCodium (licenza MIT). I modelli AI hanno le loro licenze: Qwen, per esempio, usa Apache-2.0 per la maggior parte delle taglie. Controlla sempre la scheda del modello prima di usarlo.

Nessuna garanzia

Il software è fornito «così com'è», senza garanzie di alcun tipo. Gli autori non sono responsabili di danni, perdite di dati o altri problemi derivanti dal suo uso, nei limiti consentiti dalla legge.

L'AI può sbagliare

  • Il codice, le risposte e i comandi proposti dagli agenti possono essere sbagliati, insicuri o incompleti.
  • Controlla i diff prima di accettarli e fai un backup o un commit git dei progetti importanti. /undo aiuta, ma non sostituisce un backup.
  • Le modalità auto e auto-edit modificano i file senza chiedere ogni volta. Usale solo in cartelle dove va bene.
  • Sei tu responsabile di quello che fai con il codice generato, anche per licenze e diritti d'autore.

Plugin, skill e server MCP

I plugin, le skill, gli hook e i server MCP di altre persone possono eseguire comandi sul tuo PC. Installa solo quelli di cui ti fidi: non li controlliamo noi.

Uso corretto

Non usare MyDevAgent per creare malware, attaccare sistemi senza permesso o violare leggi e diritti di altre persone.
